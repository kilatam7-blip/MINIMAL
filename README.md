# MINIMAL — Design & Development Agency

Landing page yang dibuat dengan React + Vite + TypeScript, dengan gaya visual minimalis, premium, dan editorial. Proyek ini menampilkan hero section, layanan, testimoni, portfolio, serta footer brand agency.

## Demo

Bisa kunjungi website demo:

- https://minimal-ochre.vercel.app/

## Teknologi yang Digunakan

- React 19
- Vite
- TypeScript
- Tailwind CSS
- CSS custom styling

## Fitur

- Hero section dengan layout cinematic
- Navigasi brand agency
- Section layanan / proses kerja
- Portfolio dengan filter kategori
- Testimoni pelanggan
- Desain responsif untuk berbagai ukuran layar

## Persyaratan Sistem

Pastikan Anda sudah memiliki:

- Node.js 18+
- npm atau pnpm

## Cara Menjalankan

1. Clone repositori ini
2. Masuk ke folder proyek
3. Install dependency

```bash
npm install
```

4. Jalankan development server

```bash
npm run dev -- --host 0.0.0.0
```

5. Buka browser ke URL berikut:

```text
http://localhost:5173/
```

## Build untuk Produksi

```bash
npm run build
```

Untuk melihat hasil build lokal:

```bash
npm run preview -- --host 0.0.0.0
```
